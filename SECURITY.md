# Security Policy

## Supported versions

DongNamTrip is a university project under development. Only the latest `main` branch is supported, and only the `Development` environment is currently supported. It is not production-ready.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private reporting: open the **Security** tab of the repository and choose **Report a vulnerability**. Include the affected component, steps to reproduce and the potential impact. Do not include real credentials or personal data.

This is a student project without a guaranteed response time; maintainers will acknowledge reports as soon as they can.

## Notes

The documented development accounts and password exist only for local development databases. Never reuse them anywhere else.
